# Image Handling Fix

The frontend must support:

```

```

and old local paths:

```
/uploads/image.jpg
```

Everywhere images appear:

Product cards,
Product details,
Gallery,
Admin preview,

use:

```javascript
const imgSrc = image
 ? (image.startsWith('http')
     ? image
     : `${api.base}${image}`)
 : null;
```

Never add API URL before Cloudinary URLs.
